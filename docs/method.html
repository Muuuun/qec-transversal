How the verdicts are computed

Exact and certified logical-gate analysis for stabilizer quantum codes. Given a code and a specified physical gate ansatz, the package computes the code-preserving physical transformations, their induced logical action, and machine-checkable evidence for completeness whenever the backend supports one. The results this produces are on the main page.

§AWhat the software computes

The input is a stabilizer code — commuting Pauli rows S ⊆ 𝔽₂2n, CSS or not — together with a physical gate ansatz: the shape the physical transformations are allowed to take. “One arbitrary single-qubit Clifford per qubit”, “one arbitrary Clifford on each cell of a prescribed partition of the qubits”, “a diagonal layer of level-L phase gates”, and “a qubit permutation dressed with per-qubit Cliffords” are all ansätze in this sense. Each backend turns code preservation into an exact algebraic condition on that ansatz, solves it over 𝔽₂ or ℤ2L, pushes the solutions down to their action on the k logical qubits, and reports how much of the ansatz the answer covers.

stabilizer code  +  physical gate ansatz S ⊆ 𝔽₂2n · partition, matching, diagonal level, or monomial shape
↓
code-preservation constraints linear over 𝔽₂, or a module system over ℤ2L
↓
exact algebraic / group solver kernels · certified unit groups · Schreier–Sims · graph automorphisms
↓
physical gate generators code-preserving, modulo Pauli — each verified against the code directly
↓
logical symplectic action λ : G ⟶ Sp(2k, 2), read off the quotient S⊥/S
↓
completeness certificate · lower bound · unknown with an exportable, independently checkable witness where the backend supports one

What “complete” means here. Completeness is always relative to the stated ansatz and to the given code — never to “all fault-tolerant logical gates”. A complete verdict says the returned set is provably the entire solution set of that ansatz. A search that was capped, sampled, or scoped to a subgroup is reported as a lower bound; a computation whose verification or budget failed is reported as unknown. Neither is ever converted into “no such gate exists”, and no result here bounds gates outside the ansatz it was given.

Proof-carrying computation

answer  +  mathematical witness  +  independent verification

Every claimed equality or non-existence result is accompanied by a completeness certificate where the backend supports one: constraint rows with their provenance, kernel bases, logical bases, per-generator symplectic actions, group elements. A standalone checker that imports nothing from this project re-derives each of them from first principles (§E). Searches that are sampled, capped, or otherwise incomplete are reported as lower bounds or unknown, never as negative results.

Status vocabulary

Five verdicts appear on this page and they are not interchangeable.

Where this page does print a non-existence verdict — “no strict layer acts as a nontrivial logical gate” — it is the consequence of a rank certificate (§D), not of a search that gave up.

How the Gate Zoo relates. The Transversal Gate Zoo on the main page is a census produced by these solvers: 68 codes across 23 families, with a separate external control of 25 best-known small stabilizer codes. It is the largest demonstration of the framework, not the framework's scope.

§CThe general framework: prescribed-partition preservation algebras

Fix a stabilizer code with row space S ⊆ 𝔽₂2n and a partition 𝒫 = {C₁, …, Cm} of the physical qubits. The ansatz “one arbitrary Clifford on each cell” is a block-diagonal symplectic matrix; dropping invertibility for a moment makes code preservation linear, and that is the whole trick:

A𝒫(S) = { M = ⊕C ∈ 𝒫 MC  :  S M ⊆ S }  ⊆  ⊕C ∈ 𝒫 M2|C|(𝔽₂).

A𝒫(S) is a GF(2) subspace — one kernel computation — and it is closed under multiplication, since SM ⊆ S and SM′ ⊆ S give S MM′ ⊆ S. It is therefore a finite-dimensional unital 𝔽₂-algebra, and the physical code-preserving Clifford gates of the ansatz, modulo Paulis, are exactly its symplectic units, which induce a logical action:

G𝒫 = A𝒫(S)× ∩ ∏C ∈ 𝒫 Sp(2|C|, 2),   λ : G𝒫 ⟶ Sp(2k, 2).

λ is well defined because a code-preserving M fixes S setwise and so descends to S⊥/S ≅ 𝔽₂2k; the residue of each image against the paired logical basis must lie in S, which is precisely the certificate that the descent is legitimate. For singleton cells the symplectic condition is free: over 𝔽₂ one has GL(2,2) = Sp(2,2), so the strict, site-dependent local-Clifford group is the unit group A(S)× — which is why that case is the most direct one. Cells of size two recover the fixed-matching two-local group; a single cell containing every qubit recovers the whole code-preserving Clifford group, at a cost that grows accordingly.

Computing the unit group exactly

Enumerating 2dim 𝒜 elements is viable only for small algebras, so A× is computed structurally, through the classical sequence

1 ⟶ 1 + N ⟶ A× ⟶ (A/N)× ⟶ 1,  |A×| = 2dim N ∏i |GL(di, qi)|,

with N the Jacobson radical and A/N split into simple factors Mdi(𝔽qi). Every stage is verified rather than trusted: the radical candidate from the characteristic-polynomial chain is closed into a two-sided ideal and proved nilpotent by explicit power computation; semisimplicity of the quotient is re-proved constructively by exhibiting each block acting on an irreducible module whose commutant is checked to be a field, with the dimension bookkeeping closing exactly; the generators are units by construction and are checked against the closed-form group orders by a Schreier–Sims chain. If any stage fails to verify, the result is unknown — never a smaller group reported as exact.

Constraint construction is LDPC-friendly: for a stabilizer row s the image sM is supported inside the closure of supp(s) under the partition, so a weight-w row contributes O(w) constraints rather than O(n). That is what lets the census reach codes with thousands of physical qubits (§1).

The symplectic cut as an index, not a sweep

Cutting A× down to its symplectic elements by enumerating the unit group and filtering costs |A×| steps — 393,216 of them to find the 6,144 elements of the [[8,3,2]] pair group, and nothing at all once a cell holds four qubits and |A×| passes 109. The involution removes the sweep. Write σ(M) = Ω MT Ω blockwise, so that M is blockwise symplectic exactly when σ(M) M = 1, and put φ(u) = σ(u) u. The fibers of φ are exactly the left cosets of G, so

|G| = |A×| / |im φ|,  im φ = the orbit of 1 under  a · u = σ(u) a u.

That congruence action is a right action because σ is an anti-automorphism, its orbit of 1 is im φ and its stabilizer is G — so orbit-stabilizer is the index formula, and the transversal it produces yields generators of G by Schreier's lemma rather than only a count. Each orbit step is one 𝔽₂ matrix product, since a ↦ σ(u) a u is linear in a for fixed u. Two facts make this the right trade: the orbit lies in the σ-symmetric part of A, about half the dimension, and its size is |A×|/|G| — so a large gate group makes the orbit small. The sweep and the index are expensive in opposite regimes.

Attribution. The linearisation is the stabilizer-code analogue of the Van den Nest–Dehaene–De Moor local-Clifford linearisation for graph states (Phys. Rev. A 70, 034302 (2004)), and the endomorphism/matrix-algebra viewpoint on transversal Clifford structure is developed by Dasu and Burton (arXiv:2507.10519). The algebraic observation is not claimed as new here. What this package contributes is the computation on top of it: certified unit and symplectic-unit groups for a partition the user prescribes, the induced logical image, and exportable witnesses — see §G for how that sits against neighbouring methods.

§DSpecialized solvers

The partition framework of §C covers any ansatz that factors over a fixed partition of the qubits. Several important gate classes do not have that shape — diagonal gates above the Clifford level, qubit permutations, layers over varying matchings — and several that do are cheaper, or more transparent, when extra structure is exploited. The package therefore carries specialized backends alongside the general one. Where two of them decide the same question they are cross-checked against each other; on CSS codes the general and CSS strict solvers must agree, and tests/test_cross_validation.py checks that they do.

CSS strict transversality: the shear normal form (Albert)

A strict-transversal gate applies one single-qubit Clifford to each physical qubit — no two-qubit gates, no permutations — so under the ideal layer a single-qubit fault does not propagate to any other physical qubit of the block. Write CX, CZ for the row spans of the check matrices and ⊙ for the coordinatewise product. A phase layer UZ(a) = ∏i √Ziai conjugates Xv to Xv Zv⊙a, so it preserves the stabilizer exactly when

AZ = { a ∈ 𝔽₂ⁿ : a ⊙ CX ⊆ CZ },  AX = { b ∈ 𝔽₂ⁿ : b ⊙ CZ ⊆ CX }.

For each check x of HX, the condition a ⊙ x ∈ CZ is the linear system QZ diag(x) aᵀ = 0 with QZ spanning ker HZ. Stacking all checks: AZ = ker MZ. So rank MZ = n proves the kernel is {0}.

Diagonal layers are not the whole story — a transversal gate could mix X and Z (Hadamards, a different Clifford per qubit). The completeness theorem (Albert, arXiv:2608.05688) closes that gap: every strict-transversal Clifford factors as

g = H(t) UZ(q) UX(p),  t ∈ AZ ∩ AX, q ∈ AZ, p ∈ AX, q ⊙ p = 0,

with H(t) = UZ(t)UX(t)UZ(t). Hence AZ = AX = {0} ⇒ the only strict-transversal gates are Paulis, i.e. the strict logical image is trivial mod Paulis.

Exhaustive validation We did not take the theorem on faith. For 46 codes with n ≤ 8 we enumerated all 6ⁿ assignments of arbitrary single-qubit Cliffords (up to 1,679,616 layers for the [[8,2,2]] toric code), kept those preserving the stabilizer, and compared. In every case the brute-force group, the group generated from AZ/AX alone, and the counting formula #{(t,q,p) : q⊙p = 0} agreed exactly. For the toric code the brute force found only the identity — a trivial kernel is a genuine nonexistence proof, not a blind spot of the diagonal search. This sweep is a test, not a claim: it runs as pytest -m slow tests/test_completeness.py, and the two numbers above are read out of that file so the page cannot outrun it.

Scope of this section. The completeness theorem and validation above cover the strict class. The fold verdicts use the fixed-matching analogue of the same construction — the SMZ/SMX kernels of Albert's framework on a certified ZX-duality (Breuckmann–Burton, arXiv:2202.06647; Eberhardt–Steffan, arXiv:2407.03973) — and the non-Clifford diagonal verdicts use the same coset-phase argument lifted from 𝔽₂ to ℤ2L, each with its own kernel certificate.

Fixed matchings, folds, and the two-fold group

Fix an involution τ on the qubits. A depth-one diagonal layer on that matching — √Z on single qubits, CZ across matched pairs — acts as a symplectic shear whose stabilizer-preservation condition is again linear, so the complete family is a GF(2) kernel: the fixed-matching analogue of AZ, AX above (Albert's SMZ, SMX). When τ additionally maps CX onto CZ it is a certified ZX-duality and the fold Hadamard joins the generators (Breuckmann–Burton, arXiv:2202.06647; Eberhardt–Steffan, arXiv:2407.03973). Structural duality candidates are only guesses derived from a family's algebra — each is certified or rejected by the kernel check, so an invalid candidate cannot contaminate a result. Two scopes are kept apart on this page: the fixed-matching solver is complete for the diagonal families on that matching (Levi/CNOT factor excluded), while the two-fold engine composes layers over sampled matchings with the Levi units included and can only certify fullness positively (§9, §5).

Diagonal gates in the Clifford hierarchy

A strict diagonal layer U(t) = ∏ᵢ Titi with t ∈ ℤ2Ln preserves a CSS code exactly when its branch phase is constant on every coset of CX inside ker HZ. Expanding the phase closes that condition into finitely many congruences over ℤ2L, and the solution set is computed exactly by module elimination, with a Smith-form certificate proving the returned generators span the whole kernel rather than merely satisfying it. For codes without CSS structure the general engine solves the corresponding mixed system in (t, c); it is sound always, and complete except when phase agreement is needed only on a proper support coset — a case covered by the CSS ladder and by a capped exact engine. Because a diagonal solver only sees gates diagonal in the computational basis, a frame sweep conjugates the code into each of the 3n per-qubit Pauli axis frames (Zeng, Cross, Chuang, arXiv:0706.1382): that closes the entire single-qubit transversal class at a given level provided every frame reports complete, which the census tables state per frame (§7).

Monomial and permutation automorphisms

Under the Calderbank–Rains–Shor–Sloane correspondence (IEEE Trans. Inf. Theory 44, 1369 (1998)) a stabilizer code is an additive GF(4) code, and “qubit permutation × per-qubit Clifford, modulo Pauli” is its monomial automorphism group inside S₃ ≀ Sn. The package computes it as the automorphism group of a coloured incidence graph (BLISS), then certifies every generator against the stabilizer row space and extracts its logical action symplectically. The scope distinction matters: when the stabilizer group is small enough that every nonzero element is used, the answer is basis-independent and exact; for larger codes the given generator rows are used, the same scope as the Tanner-graph literature, and the result is reported as a certified lower bound. Pure permutations are handled separately, and by two routes — the Tanner graph of the checks as given (a subgroup, always a lower bound) and characteristic bounded-weight codeword classes, which are permutation-invariant and therefore give the exact row-space automorphism group whenever the classes are enumerated and span.

One-block closure, fullness recognition, and synthesis

Products of depth-one layers over varying matchings are not a fixed ansatz, so they are handled by closure rather than by a kernel: the engine collects every depth-one one-block layer it can certify — strict shears, fold layers over sampled matchings, permutation gates — and grows the generated logical group. That direction of reasoning is one-sided by construction and the page reports it that way (§9). Two supporting engines make the verdicts usable at scale: exact group orders come from a Schreier–Sims chain cross-checked against explicit enumeration, and beyond the reach of any order computation a transvection recognition certificate (McLaughlin) decides λ(G) = Sp(2k,2) from irreducibility, orbit spanning, and the absence of an invariant quadratic form, returning “full”, “not-full”, or “inconclusive” — never a guess. In the opposite direction, a synthesis routine takes a named logical target and either returns an explicit three-layer strict implementation or proves the target lies outside the strict logical image altogether.

Scope limits, stated rather than buried

Everything on this page is modulo Paulis. Every group order here — strict, fold, monomial, one-block — is the order of a symplectic action, i.e. modulo Pauli operators and global phases. That is sound rather than sloppy: the sign defect of a Clifford on the stabilizer group is a linear character, so a Pauli correction always exists and never changes the symplectic action, which is why the orders are right. What is not computed for the fold, monomial and one-block columns is the explicit circuit-level sign fix; the tool does compute it for the strict diagonal generators, distinguishing S̄ from S̄†. Read the other columns as symplectic images, not as circuit-level claims about phases.

Two further scope limits, stated rather than buried. The one-block column collects, per matching, only the diagonal families SMZ/SMX and the fold-Hadamard: the Levi (CNOT-network) units are not collected, so that column is a floor even before its sampling and truncation are counted, and it is a different generating set from Albert's N2fold rather than a subset or a superset of it (§9). And the fold column is complete per certified duality, not over all involutions — the sweep over every matching remains open for every code here.

§ECertificates and verification

A solver that reports its own success is not evidence. Three independent layers stand behind the numbers on this page, and they are listed in increasing order of how little they ask you to trust.

1

internal certificates

Every report carries a certificate block: CSS orthogonality, canonical logical pairing, nullspace verification, per-generator symplectic checks, and a group-order cross-check (Schreier–Sims against explicit element enumeration). Kernel completeness over ℤ2L is certified by an exported Smith-form pair; unit-group orders by the verified radical/Wedderburn split of §C.

2

exportable witnesses

Verdicts are exported in two schemas — qec-transversal-strict-witness/1 for CSS strict analyses and qec-transversal-stabilizer-witness/1 for the general (including non-CSS) engine — each carrying constraint rows with their provenance, kernel bases, logical bases, gate actions, and group elements, so soundness and completeness can be re-derived without this library.

3

sign-exact circuit checks

The symplectic framework works modulo Pauli and global phase. A signed-stabilizer route closes that gap where it is run: the gate is lifted to an exact stim tableau, conjugated through the signed generators, given an explicit Pauli correction, and re-verified to fix every generator with sign +1 — distinguishing, for instance, a logical S̄ from S̄†.

§FEight kinds of “transversal” — four decided here

The word “transversal” names many inequivalent gate classes in the literature, differing in how far a single fault can spread. This zoo decides four of them for every code: strict — one depth-one layer U₁ ⊗ … ⊗ Un of independent single-qubit Cliffords, no two-qubit gates, no permutations (the strongest notion: under the ideal layer a single-qubit fault does not reach any other physical qubit of the block); non-Clifford diagonal — the same shape one or more hierarchy levels up, ∏ᵢ Tᵢ^tᵢ with t ∈ ℤ2Lⁿ; fold — single-qubit gates plus CZ across the pairs of a ZX-duality; and monomial automorphism — a qubit permutation from the code's symmetry group, dressed with per-qubit Cliffords. The first two are decided by kernel computations, complete outright; fold is complete per certified duality; monomial groups are exact for the given checks.

Two of those rows are one family with a dial. Holmes (arXiv:2606.13521, Def. 1) calls a layer W-local transversal when it factors as ⊗ᵢ Vᵢ with the Vᵢ acting on disjoint blocks of at most W qubits that partition the n physical qubits. Strict is W = 1 and depth-one two-local is W = 2 — and for those rows the “one fault spreads to” column is just the block size restated, since a fault cannot leave its block. W is the knob trading locality for power. It does not order the whole table: uniform transversal and the non-Clifford diagonal family are also W = 1, and the last two rows are not single layers at all.

For the toric and non-self-dual BB instances in this census, the transversal gates the literature discusses belong to the weaker rows below — which is why our strict verdict (“none”) and that folklore are both right. That is a statement about those instances, never about sparsity as such: the census also contains 4 self-dual bivariate bicycle codes (Liang–Chen, arXiv:2510.05211) whose weight-8 checks carry a genuine strict transversal H̄ and S̄ — certified here, in §3.

§GRelated work, and what is distinctive here

Computational work on logical gates approaches the problem from several directions, and this package implements or reuses results from most of them. The useful distinction is what is held fixed and what is computed.

Albert, “Beyond transversality: structure of Clifford circuits for CSS codes,” arXiv:2608.05688 CSS structure; strict and two-fold transversal layers normal forms for code-preserving Clifford circuits, the two-fold transversal group, and a 136-code survey — the construction the CSS backend of §D implements

Established structures implemented or extended here. CSS strict-transversal Clifford analysis and its normal form; fixed-matching and fold methods; diagonal Clifford-hierarchy search; automorphism and monomial logical-Clifford methods; the Zeng–Cross–Chuang frame reduction. These are capabilities of the package, not claims of originality, and the census reproduces published results wherever they exist (§5, §3).

Where the preservation-algebra backend sits. The methods above start from a target logical transformation, a code automorphism, a CSS normal form, or a particular diagonal/hierarchy ansatz. The backend of §C instead fixes the physical locality structure — a partition of the qubits, with an arbitrary Clifford allowed on each cell — and computes the corresponding code-preserving physical subgroup together with its logical image, exactly and with a certificate, for arbitrary stabilizer codes. The classes are not nested in either direction: automorphism and varying-matching methods reach gates no fixed partition contains, and phase-function methods reach diagonal gates above the Clifford level that a symplectic algebra does not see. No priority is claimed for the algebraic identification itself, which is older than this package (§C).

The second distinctive contribution is a software one, and it is the organising principle of this page: the integration of exact computation + certificate + independent verifier in one pipeline, with an explicit vocabulary (§A) separating what has been proved complete from what is a lower bound and what is unknown.
