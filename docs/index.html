The Strict-Transversal Gate Zoo

Every well-known quantum LDPC code, one exact linear-algebra certificate each: which codes admit a depth-one layer of single-qubit Clifford gates acting as a nontrivial logical gate — and the proof that most admit none.

37 codes · 11 families · every verdict machine-certified · computed 2026-08-10 with qec-transversal (method: Albert, arXiv:2608.05688)

§1The question

A strict-transversal gate on one code block applies one single-qubit Clifford to each physical qubit — no two-qubit gates, no qubit permutations. Faults cannot spread inside the block, so these are the cheapest fault-tolerant logical gates a code can have. The question for each code: does any such layer act as a nontrivial logical Clifford?

§2The method, in four lines

Write CX, CZ for the row spans of the check matrices HX, HZ, and ⊙ for the coordinatewise product of binary vectors. A layer of phase gates UZ(a) = ∏i √Ziai conjugates an X-type stabilizer Xv to Xv Zv⊙a. It preserves the stabilizer group exactly when every such Z-residue is again a stabilizer:

AZ = { a ∈ 𝔽₂ⁿ : a ⊙ CX ⊆ CZ },  AX = { b ∈ 𝔽₂ⁿ : b ⊙ CZ ⊆ CX }.

For each check x of HX, the condition a ⊙ x ∈ CZ is the linear system QZ diag(x) aᵀ = 0, where QZ spans ker HZ. Stacking all checks gives one matrix MZ with AZ = ker MZ.

So the entire search is a nullspace computation over 𝔽₂ — exact, fast, and certifiable: rank MZ = n is a proof that the kernel is {0}. The same construction with X and Z exchanged gives AX.

§3Why a trivial kernel is a full impossibility proof

A skeptic should object: the kernels above only cover diagonal layers (√Z- and √X-type). What about layers mixing X and Z — a Hadamard on some qubits, a different Clifford on every qubit? The answer is a completeness theorem (Albert, arXiv:2608.05688): every strict-transversal Clifford factors as

g = H(t) UZ(q) UX(p),  t ∈ AZ ∩ AX, q ∈ AZ, p ∈ AX, q ⊙ p = 0,

where H(t) = UZ(t)UX(t)UZ(t) is a subset-Hadamard. Hence AZ = AX = {0}  ⇒  the only strict-transversal gates are Pauli operators.

Exhaustive validation We did not take the theorem on faith. For 46 codes with n ≤ 8 we enumerated all 6ⁿ assignments of arbitrary single-qubit Cliffords (up to 1,679,616 layers for the [[8,2,2]] toric code), kept those preserving the stabilizer, and compared. In every case the brute-force group, the group generated from AZ/AX alone, and the counting formula #{(t,q,p) : q⊙p = 0} agreed exactly. For the toric code the brute force found only the identity — the trivial kernel is a genuine nonexistence proof, not a blind spot of the diagonal search.

Scope. This zoo certifies the strict class only. Fold-transversal gates — which add qubit permutations and two-qubit CZ layers (Breuckmann–Burton, arXiv:2202.06647; Eberhardt–Steffan, arXiv:2407.03973) — are a strictly larger class, and that is where the useful Clifford gates of bicycle codes actually live.

§5The qLDPC families: nonexistence certificates

Each entry states the code, then the certificate: the constraint matrix reaches full rank n in both sectors, so both kernels are {0} and — by §3 — no strict-transversal layer acts as a nontrivial logical gate. This is folklore-expected (the bicycle-code literature goes straight to fold-transversal constructions) but, to our knowledge, certified systematically here for the first time.

§6The codes that do have transversal gates

The exact solutions. Each filled strip is a parameter vector: apply √Z (or √X) on the filled qubits. These are the classical positive controls — self-dual or dual-containing CSS codes — and none of them is LDPC: their gates come from algebraic structure (doubly-even self-duality, Reed–Muller nesting) that check-sparsity destroys.

steane [[7,1,3]]

transversal gates exist

HX = HZ = parity checks of the [7,4,3] Hamming code. Self-dual, doubly even.

√Z on weight 7 — acts on logicals  λ = (1 1 ; 0 1)
√X on weight 7 — acts on logicals  λ = (1 0 ; 1 1)

Exact solution. dim AZ = 1 (rank MZ = 6 of n = 7), dim AX = 1. Logical group order 6 = full logical Clifford group Sp(2k,2) mod Paulis.
