§AWhat the software computes

The input is a stabilizer code — commuting Pauli rows S ⊆ 𝔽₂2n, CSS or not — together with a physical gate ansatz: the shape the physical transformations are allowed to take. “One arbitrary single-qubit Clifford per qubit”, “one arbitrary Clifford on each cell of a prescribed partition of the qubits”, “a diagonal layer of level-L phase gates”, and “a qubit permutation dressed with per-qubit Cliffords” are all ansätze in this sense. Each backend turns code preservation into an exact algebraic condition on that ansatz, solves it over 𝔽₂ or ℤ2L, pushes the solutions down to their action on the k logical qubits, and reports how much of the ansatz the answer covers.

stabilizer code  +  physical gate ansatz S ⊆ 𝔽₂2n · partition, matching, diagonal level, or monomial shape
↓
code-preservation constraints linear over 𝔽₂, or a module system over ℤ2L
↓
exact algebraic / group solver kernels · certified unit groups · Schreier–Sims · graph automorphisms
↓
physical gate generators code-preserving, modulo Pauli — each verified against the code directly
↓
logical symplectic action λ : G ⟶ Sp(2k, 2), read off the quotient S⊥/S
↓
completeness certificate · lower bound · unknown with an exportable, independently checkable witness where the backend supports one

What “complete” means here. Completeness is always relative to the stated ansatz and to the given code — never to “all fault-tolerant logical gates”. A complete verdict says the returned set is provably the entire solution set of that ansatz. A search that was capped, sampled, or scoped to a subgroup is reported as a lower bound; a computation whose verification or budget failed is reported as unknown. Neither is ever converted into “no such gate exists”, and no result here bounds gates outside the ansatz it was given.

Proof-carrying computation

answer  +  mathematical witness  +  independent verification

Every claimed equality or non-existence result is accompanied by a completeness certificate where the backend supports one: constraint rows with their provenance, kernel bases, logical bases, per-generator symplectic actions, group elements. A standalone checker that imports nothing from this project re-derives each of them from first principles (§E). Searches that are sampled, capped, or otherwise incomplete are reported as lower bounds or unknown, never as negative results.

§CThe general framework: prescribed-partition preservation algebras

Fix a stabilizer code with row space S ⊆ 𝔽₂2n and a partition 𝒫 = {C₁, …, Cm} of the physical qubits. The ansatz “one arbitrary Clifford on each cell” is a block-diagonal symplectic matrix; dropping invertibility for a moment makes code preservation linear, and that is the whole trick:

A𝒫(S) = { M = ⊕C ∈ 𝒫 MC  :  S M ⊆ S }  ⊆  ⊕C ∈ 𝒫 M2|C|(𝔽₂).

A𝒫(S) is a GF(2) subspace — one kernel computation — and it is closed under multiplication, since SM ⊆ S and SM′ ⊆ S give S MM′ ⊆ S. It is therefore a finite-dimensional unital 𝔽₂-algebra, and the physical code-preserving Clifford gates of the ansatz, modulo Paulis, are exactly its symplectic units, which induce a logical action:

G𝒫 = A𝒫(S)× ∩ ∏C ∈ 𝒫 Sp(2|C|, 2),   λ : G𝒫 ⟶ Sp(2k, 2).

λ is well defined because a code-preserving M fixes S setwise and so descends to S⊥/S ≅ 𝔽₂2k; the residue of each image against the paired logical basis must lie in S, which is precisely the certificate that the descent is legitimate. For singleton cells the symplectic condition is free: over 𝔽₂ one has GL(2,2) = Sp(2,2), so the strict, site-dependent local-Clifford group is the unit group A(S)× — which is why that case is the most direct one. Cells of size two recover the fixed-matching two-local group; a single cell containing every qubit recovers the whole code-preserving Clifford group, at a cost that grows accordingly.

Computing the unit group exactly

Enumerating 2dim 𝒜 elements is viable only for small algebras, so A× is computed structurally, through the classical sequence

1 ⟶ 1 + N ⟶ A× ⟶ (A/N)× ⟶ 1,  |A×| = 2dim N ∏i |GL(di, qi)|,

with N the Jacobson radical and A/N split into simple factors Mdi(𝔽qi). Every stage is verified rather than trusted: the radical candidate from the characteristic-polynomial chain is closed into a two-sided ideal and proved nilpotent by explicit power computation; semisimplicity of the quotient is re-proved constructively by exhibiting each block acting on an irreducible module whose commutant is checked to be a field, with the dimension bookkeeping closing exactly; the generators are units by construction and are checked against the closed-form group orders by a Schreier–Sims chain. If any stage fails to verify, the result is unknown — never a smaller group reported as exact.

Constraint construction is LDPC-friendly: for a stabilizer row s the image sM is supported inside the closure of supp(s) under the partition, so a weight-w row contributes O(w) constraints rather than O(n). That is what lets the census reach codes with thousands of physical qubits (§4).

The symplectic cut as an index, not a sweep

Cutting A× down to its symplectic elements by enumerating the unit group and filtering costs |A×| steps — 393,216 of them to find the 6,144 elements of the [[8,3,2]] pair group, and nothing at all once a cell holds four qubits and |A×| passes 109. The involution removes the sweep. Write σ(M) = Ω MT Ω blockwise, so that M is blockwise symplectic exactly when σ(M) M = 1, and put φ(u) = σ(u) u. The fibers of φ are exactly the left cosets of G, so

|G| = |A×| / |im φ|,  im φ = the orbit of 1 under  a · u = σ(u) a u.

That congruence action is a right action because σ is an anti-automorphism, its orbit of 1 is im φ and its stabilizer is G — so orbit-stabilizer is the index formula, and the transversal it produces yields generators of G by Schreier's lemma rather than only a count. Each orbit step is one 𝔽₂ matrix product, since a ↦ σ(u) a u is linear in a for fixed u. Two facts make this the right trade: the orbit lies in the σ-symmetric part of A, about half the dimension, and its size is |A×|/|G| — so a large gate group makes the orbit small. The sweep and the index are expensive in opposite regimes.

How wide must a fixed partition be?

With cells wider than three qubits decidable, one can ask what the framework is really measuring: the smallest cell width at which a single fixed partition carries the whole logical Clifford group. Chakraborty and Gottesman (arXiv:2602.13395, Theorem 1) prove that width ≥ k is necessary — their gadget sets share one partition, which is the hypothesis that does the work — and give a tight example: k blocks of the [[7,1,3]] code, cells being corresponding qubits. They note the construction does not extend to single-block codes encoding several logical qubits, and leave that case open.

Two readings, offered at the strength the data supports. The narrow one is secure: the Chakraborty–Gottesman bound is necessary but not sufficient, and the gap is code-dependent — width k suffices for the decomposable control and for none of the indecomposable codes measured. The broader one is a conjecture, not a result: that for k ≥ 2 a fixed partition of width k carries Sp(2k,2) only when the code factorises into k codes of one logical qubit each, with every cell meeting each factor once. 6 indecomposable codes and one decomposable control are evidence, not a proof, and the indecomposable codes drawn from best-known tables are unstructured enough that their fixed groups are small for want of any symmetry at all — [[8,3,3]] at 1,920 and [[8,3,2]] at 384 are the evidentially strong negatives.

The contrast with varying partitions is the sharper fact, and it is what the no-go hypothesis is really constraining. In all 6 exhaustive rows the group generated by depth-one layers over all partitions of that same width is the full logical Clifford group, while the best single fixed partition reaches a small fraction of it. Letting the pairing change between layers — not making the gates bigger — is what buys the group (§3, and the one-block column of §4).

§DSpecialized solvers

The partition framework of §C covers any ansatz that factors over a fixed partition of the qubits. Several important gate classes do not have that shape — diagonal gates above the Clifford level, qubit permutations, layers over varying matchings — and several that do are cheaper, or more transparent, when extra structure is exploited. The package therefore carries specialized backends alongside the general one. Where two of them decide the same question they are cross-checked against each other; on CSS codes the general and CSS strict solvers must agree, and tests/test_cross_validation.py checks that they do.

CSS strict transversality: the shear normal form (Albert)

A strict-transversal gate applies one single-qubit Clifford to each physical qubit — no two-qubit gates, no permutations — so under the ideal layer a single-qubit fault does not propagate to any other physical qubit of the block. Write CX, CZ for the row spans of the check matrices and ⊙ for the coordinatewise product. A phase layer UZ(a) = ∏i √Ziai conjugates Xv to Xv Zv⊙a, so it preserves the stabilizer exactly when

AZ = { a ∈ 𝔽₂ⁿ : a ⊙ CX ⊆ CZ },  AX = { b ∈ 𝔽₂ⁿ : b ⊙ CZ ⊆ CX }.

For each check x of HX, the condition a ⊙ x ∈ CZ is the linear system QZ diag(x) aᵀ = 0 with QZ spanning ker HZ. Stacking all checks: AZ = ker MZ. So rank MZ = n proves the kernel is {0}.

Diagonal layers are not the whole story — a transversal gate could mix X and Z (Hadamards, a different Clifford per qubit). The completeness theorem (Albert, arXiv:2608.05688) closes that gap: every strict-transversal Clifford factors as

g = H(t) UZ(q) UX(p),  t ∈ AZ ∩ AX, q ∈ AZ, p ∈ AX, q ⊙ p = 0,

with H(t) = UZ(t)UX(t)UZ(t). Hence AZ = AX = {0} ⇒ the only strict-transversal gates are Paulis, i.e. the strict logical image is trivial mod Paulis.

Exhaustive validation We did not take the theorem on faith. For 46 codes with n ≤ 8 we enumerated all 6ⁿ assignments of arbitrary single-qubit Cliffords (up to 1,679,616 layers for the [[8,2,2]] toric code), kept those preserving the stabilizer, and compared. In every case the brute-force group, the group generated from AZ/AX alone, and the counting formula #{(t,q,p) : q⊙p = 0} agreed exactly. For the toric code the brute force found only the identity — a trivial kernel is a genuine nonexistence proof, not a blind spot of the diagonal search. This sweep is a test, not a claim: it runs as pytest -m slow tests/test_completeness.py, and the two numbers above are read out of that file so the page cannot outrun it.

Scope of this section. The completeness theorem and validation above cover the strict class. The fold verdicts use the fixed-matching analogue of the same construction — the SMZ/SMX kernels of Albert's framework on a certified ZX-duality (Breuckmann–Burton, arXiv:2202.06647; Eberhardt–Steffan, arXiv:2407.03973) — and the non-Clifford diagonal verdicts use the same coset-phase argument lifted from 𝔽₂ to ℤ2L, each with its own kernel certificate.

Fixed matchings, folds, and the two-fold group

Fix an involution τ on the qubits. A depth-one diagonal layer on that matching — √Z on single qubits, CZ across matched pairs — acts as a symplectic shear whose stabilizer-preservation condition is again linear, so the complete family is a GF(2) kernel: the fixed-matching analogue of AZ, AX above (Albert's SMZ, SMX). When τ additionally maps CX onto CZ it is a certified ZX-duality and the fold Hadamard joins the generators (Breuckmann–Burton, arXiv:2202.06647; Eberhardt–Steffan, arXiv:2407.03973). Structural duality candidates are only guesses derived from a family's algebra — each is certified or rejected by the kernel check, so an invalid candidate cannot contaminate a result. Two scopes are kept apart on this page: the fixed-matching solver is complete for the diagonal families on that matching (Levi/CNOT factor excluded), while the two-fold engine composes layers over sampled matchings with the Levi units included and can only certify fullness positively (§3, §5).

Diagonal gates in the Clifford hierarchy

A strict diagonal layer U(t) = ∏ᵢ Titi with t ∈ ℤ2Ln preserves a CSS code exactly when its branch phase is constant on every coset of CX inside ker HZ. Expanding the phase closes that condition into finitely many congruences over ℤ2L, and the solution set is computed exactly by module elimination, with a Smith-form certificate proving the returned generators span the whole kernel rather than merely satisfying it. For codes without CSS structure the general engine solves the corresponding mixed system in (t, c); it is sound always, and complete except when phase agreement is needed only on a proper support coset — a case covered by the CSS ladder and by a capped exact engine. Because a diagonal solver only sees gates diagonal in the computational basis, a frame sweep conjugates the code into each of the 3n per-qubit Pauli axis frames (Zeng, Cross, Chuang, arXiv:0706.1382): that closes the entire single-qubit transversal class at a given level provided every frame reports complete, which the census tables state per frame (§8).

Monomial and permutation automorphisms

Under the Calderbank–Rains–Shor–Sloane correspondence (IEEE Trans. Inf. Theory 44, 1369 (1998)) a stabilizer code is an additive GF(4) code, and “qubit permutation × per-qubit Clifford, modulo Pauli” is its monomial automorphism group inside S₃ ≀ Sn. The package computes it as the automorphism group of a coloured incidence graph (BLISS), then certifies every generator against the stabilizer row space and extracts its logical action symplectically. The scope distinction matters: when the stabilizer group is small enough that every nonzero element is used, the answer is basis-independent and exact; for larger codes the given generator rows are used, the same scope as the Tanner-graph literature, and the result is reported as a certified lower bound. Pure permutations are handled separately, and by two routes — the Tanner graph of the checks as given (a subgroup, always a lower bound) and characteristic bounded-weight codeword classes, which are permutation-invariant and therefore give the exact row-space automorphism group whenever the classes are enumerated and span.

One-block closure, fullness recognition, and synthesis

Products of depth-one layers over varying matchings are not a fixed ansatz, so they are handled by closure rather than by a kernel: the engine collects every depth-one one-block layer it can certify — strict shears, fold layers over sampled matchings, permutation gates — and grows the generated logical group. That direction of reasoning is one-sided by construction and the page reports it that way (§3). Two supporting engines make the verdicts usable at scale: exact group orders come from a Schreier–Sims chain cross-checked against explicit enumeration, and beyond the reach of any order computation a transvection recognition certificate (McLaughlin) decides λ(G) = Sp(2k,2) from irreducibility, orbit spanning, and the absence of an invariant quadratic form, returning “full”, “not-full”, or “inconclusive” — never a guess. In the opposite direction, a synthesis routine takes a named logical target and either returns an explicit three-layer strict implementation or proves the target lies outside the strict logical image altogether.

Scope limits, stated rather than buried

Everything on this page is modulo Paulis. Every group order here — strict, fold, monomial, one-block — is the order of a symplectic action, i.e. modulo Pauli operators and global phases. That is sound rather than sloppy: the sign defect of a Clifford on the stabilizer group is a linear character, so a Pauli correction always exists and never changes the symplectic action, which is why the orders are right. What is not computed for the fold, monomial and one-block columns is the explicit circuit-level sign fix; the tool does compute it for the strict diagonal generators, distinguishing S̄ from S̄†. Read the other columns as symplectic images, not as circuit-level claims about phases.

Two further scope limits, stated rather than buried. The one-block column collects, per matching, only the diagonal families SMZ/SMX and the fold-Hadamard: the Levi (CNOT-network) units are not collected, so that column is a floor even before its sampling and truncation are counted, and it is a different generating set from Albert's N2fold rather than a subset or a superset of it (§3). And the fold column is complete per certified duality, not over all involutions — the sweep over every matching remains open for every code here.

§ECertificates and verification

A solver that reports its own success is not evidence. Three independent layers stand behind the numbers on this page, and they are listed in increasing order of how little they ask you to trust.

1

internal certificates

Every report carries a certificate block: CSS orthogonality, canonical logical pairing, nullspace verification, per-generator symplectic checks, and a group-order cross-check (Schreier–Sims against explicit element enumeration). Kernel completeness over ℤ2L is certified by an exported Smith-form pair; unit-group orders by the verified radical/Wedderburn split of §C.

2

exportable witnesses

Verdicts are exported in two schemas — qec-transversal-strict-witness/1 for CSS strict analyses and qec-transversal-stabilizer-witness/1 for the general (including non-CSS) engine — each carrying constraint rows with their provenance, kernel bases, logical bases, gate actions, and group elements, so soundness and completeness can be re-derived without this library.

3

sign-exact circuit checks

The symplectic framework works modulo Pauli and global phase. A signed-stabilizer route closes that gap where it is run: the gate is lifted to an exact stim tableau, conjugated through the signed generators, given an explicit Pauli correction, and re-verified to fix every generator with sign +1 — distinguishing, for instance, a logical S̄ from S̄†.

§1Eight kinds of “transversal” — four decided here

The word “transversal” names many inequivalent gate classes in the literature, differing in how far a single fault can spread. This zoo decides four of them for every code: strict — one depth-one layer U₁ ⊗ … ⊗ Un of independent single-qubit Cliffords, no two-qubit gates, no permutations (the strongest notion: under the ideal layer a single-qubit fault does not reach any other physical qubit of the block); non-Clifford diagonal — the same shape one or more hierarchy levels up, ∏ᵢ Tᵢ^tᵢ with t ∈ ℤ2Lⁿ; fold — single-qubit gates plus CZ across the pairs of a ZX-duality; and monomial automorphism — a qubit permutation from the code's symmetry group, dressed with per-qubit Cliffords. The first two are decided by kernel computations, complete outright; fold is complete per certified duality; monomial groups are exact for the given checks.

Two of those rows are one family with a dial. Holmes (arXiv:2606.13521, Def. 1) calls a layer W-local transversal when it factors as ⊗ᵢ Vᵢ with the Vᵢ acting on disjoint blocks of at most W qubits that partition the n physical qubits. Strict is W = 1 and depth-one two-local is W = 2 — and for those rows the “one fault spreads to” column is just the block size restated, since a fault cannot leave its block. W is the knob trading locality for power. It does not order the whole table: uniform transversal and the non-Clifford diagonal family are also W = 1, and the last two rows are not single layers at all.

For the toric and non-self-dual BB instances in this census, the transversal gates the literature discusses belong to the weaker rows below — which is why our strict verdict (“none”) and that folklore are both right. That is a statement about those instances, never about sparsity as such: the census also contains 4 self-dual bivariate bicycle codes (Liang–Chen, arXiv:2510.05211) whose weight-8 checks carry a genuine strict transversal H̄ and S̄ — certified here, in §7.

§3The ceiling — and the loophole

The strict and fold columns below are final, not artifacts of a weak search. Chakraborty–Gottesman (arXiv:2602.13395) prove that no stabilizer code implements the full logical Clifford group with strict transversal gates (k ≥ 2), with code automorphisms (k ≥ 2), or with fold gates over any single fixed pairing (k ≥ 3; bare qubit permutations fail already at k = 1). A gadget set with one fixed partition is closed under composition — that is what makes it constant-depth — and every such constant-depth class has this theorem ceiling. The certified groups in this census sit at or near it, and the statistic the theorem bounds is the per-duality one: every one of the 69 certified ZX-dualities in the zoo generates a logical group of order 6 against targets up to ~1090, and no stronger search over that fixed pairing would change it. The census's “fold gates?” column reports something else — the group generated by all of a code's certified dualities together — which is precisely the composition the theorem does not bound. §5 keeps the two apart.

The same paper names the loophole. Sequences of depth-one fold layers over varying pairings escape the theorem: the union of layers over different dualities is not closed under composition, so it forms no group and the constant-depth hypothesis fails — the price is depth that grows with the target gate, one depth-one layer at a time, plus whatever error correction a given implementation inserts between them. And the loophole is real: arXiv:2602.09788 proves this route reaches the full, individually addressable logical Clifford group for the middle Reed–Muller family — tesseract, rm64, and rm256 in this census — on one block, with no ancillas and no measurements.

The census column one-block group is not a new concept: the question, and the fullness criterion λ = Sp(2k,2) it is checked against, are Albert's (arXiv:2608.05688), who defines the two-fold transversal group N2fold over the union of matchings on one block, defines a two-fold automorphism group in which a depth-one two-local circuit need only be code-preserving up to a permutation, and tabulates 136 CSS codes, 78 of them full. But this column is not N2fold, and says so plainly: it generates from every strict gate, the diagonal fold families and fold-Hadamard of every certified matching, and every automorphism gate — permutation gates included, Levi (CNOT-network) units excluded. His group has the Levi factor this one lacks; this one has the permutation gates his N2fold lacks. Neither contains the other, so these orders are not comparable with his per-code numbers and no comparison is drawn anywhere on this page. What the column contributes is coverage and certification: exact orders under the one-sided rule below, for families his table does not reach (Cornucopia, APM-Kasai, self-dual bicycle). (Certified matching, not certified ZX-duality: a matching layer that passes its own kernel check is a legitimate gate whether or not the involution happens to be a duality.) Escaping the ceiling does not always take varying matchings, either — cube-832 reaches the full Sp(6,2) from a single certified matching (affine-0), provided its automorphism gates come too; strict layers plus that one matching alone fall short. It evades the theorem because at least one automorphism generator fails to normalize that involution, so the set is not a fixed-partition gadget set.

The badge is one-sided by construction. A FULL λ=Sp(2k,2) badge is a positive certificate: within the one-block gate model considered here, the logical symplectic image generated by the certified depth-one layers equals Sp(2k,2) — the full logical Clifford group modulo logical Paulis and global phase. It is a statement about that generated image, not about any particular circuit implementation, and it says nothing about how deep the circuits are (see below). Every other entry is printed as a lower bound (≥), never as a negative — a code's involutions cannot be enumerated (the solver samples them), so falling short of the target means “the layers found do not suffice”, not “the code cannot get there”. Publishing that as a no-go would be a failed search dressed as a proof. One consequence worth stating: on the largest codes the closure is truncated at a work budget, so the sweep's own floor can land below an order the fold column certifies exactly. Since every fold layer is a depth-one one-block layer, the fold group is a subgroup here and its certified order is itself a valid floor, so the cell shows whichever of the two is larger and the tooltip names both. No cell mixes the two into a new number.

What fullness costs: a depth floor, and how far below the truth it sits

A FULL badge says a code can reach every logical Clifford. It says nothing about how long the circuit is — and that turns out to be the whole story as k grows. The argument is pure counting: with G distinct depth-one layers, a depth-D circuit can express at most GD logical actions, so reaching a group of order |Sp(2k,2)| requires

D ≥ logG |Sp(2k,2)|,  |Sp(2k,2)| = 2k² ∏i=1..k(4i − 1) ~ 2k².

Both inputs are already in this census — G is the layer count behind each one-block verdict, and the target is fixed by k — so the chart below is a measurement of the data on this page, not a separate experiment. Note what the k² in the chart is: the target's exponent grows like k² by definition, so D = k²·log 2 / log G is arithmetic, not a discovered law. The measurement is G — how large an instruction set each code actually certifies — and across this census G stays in the low hundreds, which is why the floors line up near a slope-2 line. Whether G stays bounded for larger codes is not something this census can say; here it is capped by our own sampler at 48 matchings.

The circles are the floor, one per code, for all 12 codes certified FULL in the one-block class (9 markers — codes agreeing on both k and D share one, and the tooltip names them). From k ≥ 6 they track the slope-2 line closely: D/k² stays between 0.27 and 0.33 while the target itself spans 23 to 353 decimal digits. The largest is grid-6x8: k = 24, 146 certified layers, so at least 164 layers to reach an arbitrary logical Clifford.

But a floor is not the answer, and the squares show by how much. Where the group is small enough to enumerate we ran the only thing that settles it — breadth-first search over the whole Cayley graph, whose last level is the true worst-case depth. That is feasible for 6 codes, up to k = 3 (|Sp(6,2)| = 1,451,520 elements); beyond that the group is larger than anything enumerable and only the floor is known. No square sits below its circle — as it cannot — and the excess runs from 1.00× (exact) to 2.00×. Two readings follow, and they matter more than the trend line:

First, the gap widens with k: at k = 1 the floor is exact; at k = 2 it understates by 1.33–1.67×; at k = 3 it understates by 2.00×. Three points is too few to fit anything, but the direction is unambiguous, and it is the wrong direction for extrapolating the floor. The 164 for grid-6x8 at k = 24 should therefore be read strictly as “at least”, with the truth plausibly several times higher — not as an estimate. Second — and this is what no counting argument can fix — c4-22 and c6-22 have the same k, the same target group of 720, and the same floor of 3, yet true depths of 4 and 5. The floor sees only how many layers exist; the depth depends on how they compose, which is exactly the information counting throws away.

Put the two halves together and the section says something sharper than its chart. The circles sit near 0.32 k², and every exact value sits on or above its circle by a factor that is itself growing with k. So the honest reading is not “depth grows like k²” — that exponent was arithmetic before any code was analysed — but depth is at least about 0.32 k². The dashed line is a floor on a floor. The exact small-k synthesis depths increasingly exceed the elementary counting bound, but 6 exact points are not enough to determine the asymptotic scaling of the true depth; nothing here bounds it from above at any k, and above k = 3 nothing here measures it at all.

Read this as an instruction-set statement, not a theorem. D is the depth needed using the layer set this tool certified; a code may admit layers the sampler never drew, and more layers would lower the floor. That is also why 5 of the 12 codes are drawn hollow: their search hit the cap of 48 matchings, so their G — and hence their D — is itself bounded by our budget rather than by the code. The counting argument is the second term of Corollary 1 in arXiv:2606.13521, which pairs it with a second bound from information spreading (Pauli radius against distance) that this census does not have the data to evaluate. Nothing here is a lower bound on what some circuit could do — only on what these gates can.

The practical reading is the one the FULL badge hides: fullness is not free and does not stay cheap. Steane reaches the whole Clifford group in 2 layers; grid-6x8, with 24 logical qubits, needs at least 164. That number is a circuit depth in depth-one layers. If a particular fault-tolerant implementation requires error correction between successive transversal layers, it translates into the corresponding number of error-correction cycles — an implementation-dependent overhead this calculation does not model. Either way, transversality buys constant depth per gate, never per algorithm.

§5How much of the Clifford group do you actually get?

Having a transversal gate and having all Clifford gates transversally are very different things. The census column “strict group” shows both numbers for every code: the order of the group its transversal gates generate, against the target |Sp(2k,2)| — the full logical Clifford group on its k qubits. Three tiers cover the whole zoo:

3 codes

the full Clifford group

“Full” is always relative to a gate class — the ★ marks it and its tooltip names the class. In the registry: steane (via strict, fold, two-local, monomial); surface-5 (via fold, two-local); doubled41-2608.11160 (via strict, fold, two-local); outside it, the non-CSS [[5,1,3]] (§6 callout) reaches it only in the monomial class. All 3 registry entries encode a single logical qubit; that is no accident, since these gates act globally and k = 1 leaves nothing to address individually — and it is exactly the regime §9 shows is left open by the k ≥ 2 no-go.

This count is class-specific, and a wider class does better. It counts the strict, fold, two-local and monomial classes only. The one-block class of §3 — the varying-layer route, which the constant-depth no-go does not bound — certifies the full logical symplectic image λ(G) = Sp(2k,2) on 12 of the 65 codes, including codes with k as large as 24. Those rows carry a FULL badge in the census rather than a ★ here, because they buy fullness with permutation gates and layers over a matching — real gates, but costlier ones than a bare transversal layer.

And the count grows in the multi-matching class. Composing depth-one two-local layers over many matchings (Albert's N2fold, Levi units included — a different generating set from §3's one-block column, which trades those CNOT units for permutation gates, so neither group contains the other; sampled with automorphism-seeded matchings, positive certificates only), more codes certify the full logical Clifford group: grid-4x6 — all of Sp(16,2), order ~6×1040 — plus iceberg-8 (Sp(12,2)), cube-832 (Sp(6,2)), and c6-22 / c4-22 (Sp(4,2)); two Steane blocks likewise certify full Sp(4,2) via the inter-block pairing. Those are a sampled lower bound, not a census column, which is why they carry no ★. None of these is new here: they reproduce Albert's census (arXiv:2608.05688), and iceberg fullness is a corollary of the Iceberg code's own structure — every two-qubit logical operator has weight-2 physical support, so the Siegel generators of Sp(2k,2) are single two-qubit rotations (Self et al., Nature Physics 20, 219 (2024), arXiv:2211.06703; all 720 elements of the [[4,2,2]] group are constructed exhaustively in arXiv:2505.20261). They are here as reproductions that exercise the solver, not as findings.

Three numbers get called “the fold group”; the census keeps them apart.

Per certified duality — one fixed ZX-duality, its diagonal fold layers plus fold-Hadamard: all 69 certified dualities in the zoo give order 6, without exception. Per fixed matching — the complete depth-one two-local group NM, one- and two-qubit Cliffords, on that matching: also order 6 on all 50 codes where it was computed, so on those matchings the fold gates were already everything. Combined across dualities — the census column — is the group generated by all of a code's certified dualities together, and it only exceeds a single duality's group when a code has more than one: bb72 276,480, coprime154 258,048, gross 184,320, bb360 184,320. gross is the case to keep straight: 6 per duality and per matching, 184,320 for its two dualities combined.

Against targets that grow like 2k² — 91 digits for the gross code — all three are negligible, and the gates are collective: one S̄, H̄, or all-pairs CZ̄ hitting every logical qubit at once. No code in this census addresses a single logical qubit in the strict or fold classes — which is what lattice surgery, automorphism circuits, and teleportation are for.

That is a fact about these codes and these classes, not about transversality. Individually targeted logical Cliffords are constructible: Holmes (arXiv:2606.13521) builds a CSS family whose depth-one 2-local layers realize the full addressable basis {S̄i, √X̄i, CZ̄i,j} in constant depth. The price is the one this whole page keeps charging: those codes are dense, explicitly non-LDPC. Addressing is bought with check weight, not obtained for free.

universality — forbidden

No code has a universal transversal set; the Eastin–Knill theorem rules it out for every code with distance ≥ 2. The zoo shows the forced trade: QRM15 buys a transversal T̄ at the price of its Clifford group (order 2, no transversal H̄), while Steane has the whole Clifford group but no T̄. Every code sits on one side of this line.

The [[5,1,3]] perfect code (non-CSS): its strict-transversal group is the cyclic C₃ = ⟨(SH)⊗5⟩, and its full monomial group (order 360) realizes the complete logical Clifford group — both computed exactly by the general-stabilizer solver and verified against 6⁵ brute force.

§7The codes with strict gates: exact solutions

The exact solutions. Each filled strip is a parameter vector: apply √Z (or √X) on the filled qubits. Most are the classical positive controls — self-dual or dual-containing CSS codes whose gates come from dense algebraic structure (doubly-even self-duality, Reed–Muller nesting). 4 of them are not: sdbb16-2510.05211, sdbb64-2510.05211, sdbb152-2510.05211 and sdbb160-2510.05211 are weight-8 LDPC codes that nonetheless carry a strict transversal layer.

The sparse positive control

It would be easy to read §6 as “sparsity destroys strict transversality”. It does not, and this registry now contains the counterexample rather than merely citing it. Liang–Chen's self-dual bivariate bicycle codes (arXiv:2510.05211) put HX = HZ = [F | FT] on a twisted torus: the checks have weight 8, so the code is LDPC, and they are doubly even, so H⊗n and S⊗n both preserve the stabilizer. Our solver certifies dim AZ = dim AX = 1 and logical group order 6 on all 4 instances — an independent reproduction of their transversal H̄/S̄ claim from the check matrices alone. The same holds classically for the 2D color codes (Steane is the smallest member); and sparse codes with transversal non-Clifford gates exist too (arXiv:2410.14662, arXiv:2310.16982).

So the certified claim is the narrow one: each qLDPC instance listed in §6 has a trivial strict logical image mod Paulis — 43 codes across 11 construction families, each with its own rank certificate. That is a statement about those 43 codes, and the self-dual BB rows are the standing reminder that it does not generalize to sparsity as such.

So which code with gates is “best”? Three answers

By encoding rate k/n alone: the iceberg family [[2m, 2m−2, 2]] — iceberg-12 = [[12,10,2]] holds the zoo record at rate 5/6, and the family reaches rate → 1. But distance is frozen at 2: these codes only detect errors. Raw rate is a misleading scoreboard.

By the operational figure of merit kd²/n (surface code ≈ 1, the qldpc-challenge metric): the middle Reed–Muller family wins decisively — rm256 = [[256,70,16]] scores kd²/n = 70 and rm64 = [[64,20,8]] scores 20, versus 12 for the gross code, 13.5 for two-gross, and ≤ 24.5 for bb756. In this family kd²/n = C(m, m/2) is unbounded — but the checks are dense (weight 32–256 at n = 256), so the LDPC property is the price of admission.

Within LDPC: the self-dual BB rows win outright — sdbb160-2510.05211 scores kd²/n = 12.8 at weight-8 checks and a strict transversal gate, which no other sparse code here manages. But the strict group it buys is order 6, a global S̄/H̄ action, not addressability. Everywhere else in §6 the strict class is empty and the certified fold layer softens it only a little: order 6 per duality, and even the largest combined group, 276,480 on bb72, is far short of the full logical Clifford group. High rate, growing distance, sparse checks, and a large transversal-class gate group in one code remains open territory.

§9k = 1 strict fullness — the regime left open by Chakraborty–Gottesman

For one logical qubit the full logical Clifford group mod Paulis is Sp(2,2) ≅ S₃, order 6. Chakraborty–Gottesman (arXiv:2602.13395) close the k ≥ 2 regime with a no-go for strict fullness; k = 1 is the regime their result leaves open. The open question, precisely: characterize all k = 1 stabilizer codes whose strict-transversal group mod Pauli is the full Sp(2,2). One positive family is classical and well known — self-dual doubly-even CSS codes (the 2D color codes, Steane the smallest member) — so nothing here claims novelty for Steane's fullness. What this section adds is certified data points on the question, from the registry and the external census above; it is a data table on an open classification problem, not a new finding.

§FRelated work, and what is distinctive here

Computational work on logical gates approaches the problem from several directions, and this package implements or reuses results from most of them. The useful distinction is what is held fixed and what is computed.

Established structures implemented or extended here. CSS strict-transversal Clifford analysis and its normal form; fixed-matching and fold methods; diagonal Clifford-hierarchy search; automorphism and monomial logical-Clifford methods; the Zeng–Cross–Chuang frame reduction. These are capabilities of the package, not claims of originality, and the census reproduces published results wherever they exist (§5, §7).

Where the preservation-algebra backend sits. The methods above start from a target logical transformation, a code automorphism, a CSS normal form, or a particular diagonal/hierarchy ansatz. The backend of §C instead fixes the physical locality structure — a partition of the qubits, with an arbitrary Clifford allowed on each cell — and computes the corresponding code-preserving physical subgroup together with its logical image, exactly and with a certificate, for arbitrary stabilizer codes. The classes are not nested in either direction: automorphism and varying-matching methods reach gates no fixed partition contains, and phase-function methods reach diagonal gates above the Clifford level that a symplectic algebra does not see. No priority is claimed for the algebraic identification itself, which is older than this package (§C).

The second distinctive contribution is a software one, and it is the organising principle of this page: the integration of exact computation + certificate + independent verifier in one pipeline, with an explicit vocabulary (§A) separating what has been proved complete from what is a lower bound and what is unknown.
